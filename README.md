# Alice: The Rabbit Hole Loop (Unity)

## Overview
**Alice: The Rabbit Hole Loop** is a narrative and strategic game inspired by **Loop Hero**, **Alice in Wonderland**, **Möbius loops**, and **word-building games such as Scrabble**.  
The player embodies **Alice**, trapped in an endless rabbit hole where logic bends and thoughts slowly unravel. Her goal is to escape by discovering how to open a mysterious door, learning that only the **White Rabbit** can truly help her.

Guided by the **Cheshire Cat** and aided by strange bottles and cakes that alter her size, Alice must navigate a world where words shape reality—before madness overtakes her.

## Core Gameplay
The game is built around a **card-based word system**:
- Each card contains a specific number of letters.
- Players form **words** to:
  - Progress through the loop
  - Interact with the environment
  - Communicate with NPCs
  - Trigger narrative events

## Key Mechanics
- **Size Alteration**: Alice’s size affects access to areas, interactions, and puzzles.
- **Narrative NPCs**:
  - The **Cheshire Cat**, cryptic guide and unreliable ally.
  - The **White Rabbit**, central to the escape.
- **Madness System**: Losing coherence in thought or misusing words accelerates mental collapse.
